## What I Learned in This Project

1. **React Router DOM (Page Navigation)**:
   - How to set up navigation between different pages (`BrowserRouter`, `Routes`, `Route`).
   - How to pass dynamic values in URLs using `useParams` (e.g., `/courses/:courseid`).
   - How to create nested pages using `<Outlet />` (e.g., `/product/men` and `/product/women`).
   - How to make Back and Next buttons using the `useNavigate` hook.
   - How to show a 404 "Page Not Found" screen for invalid links.
