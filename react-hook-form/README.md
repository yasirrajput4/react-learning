# React Hook Form with Tailwind CSS

## What I Learned in This Project

1. **React Hook Form (Form Management & Validation)**:
   - How to manage input fields efficiently without creating extra `useState` hooks using `register`.
   - How to apply input validation rules (`required`, `minLength`, `maxLength`).
   - How to capture form data cleanly using the `handleSubmit` wrapper.
   - How to access and display error messages conditionally using the `errors` object.

2. **Asynchronous Handling & Form Lifecycle**:
   - How to simulate API calls and track loading state using `isSubmitting`.
   - How to disable the submit button during submission to prevent duplicate clicks.
   - How to clear all input fields and reset error states after submission using `reset()`.
